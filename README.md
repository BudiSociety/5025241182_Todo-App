## 📋 Deskripsi
Aplikasi Todo List sederhana yang dibangun menggunakan **HTML** dan **CSS** murni (tanpa JavaScript), sesuai dengan ketentuan tugas. Aplikasi ini menampilkan:

- Tata letak dua panel (daftar tugas & detail tugas) menggunakan **CSS Grid**
- Struktur halaman menggunakan elemen semantik HTML (`header`, `main`, `aside`, `section`, `footer`)
- Formulir statis untuk menambahkan tugas baru
- Data tugas berupa dummy data statis
- Tampilan yang responsif untuk desktop maupun mobile
